# thirdyearproject

To run the code on your own device, download the file from GitHub and put it in a good location. Then enter the directory /cbrs and run the shell script named "setup.sh". 

This will install all the required pip packages, spaCy models and nltk corpora, so may require space. Allow the installation to complete in full. If you encounter any errors during this phase you may need to install relevant pip packages manually or export the location that packages were installed to the PATH. 

Now all applications should run (note that for the first run through of any application, large language models may need to be downloaded from HuggingFace, which can take time depending on your internet connection) from the command line

To run the main project use "python3 run_cbrs.py" in the "cbrs" folder.
